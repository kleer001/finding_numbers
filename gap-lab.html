Digit gap tuner

One digit, over and over, in groups of four, through the game's real audio chain — the same band-limiting, saturation, ducking and deep-level noise bed a level-40 readout goes through. Find the tightest gap where you can still count four, and tell me the number.

Gap is onset to onset, not silence between. The voice samples run 0.60s to 1.63s — every one of them longer than this slider's maximum — so at any setting here the digits overlap. There is no "clean" end of this dial; the question is only how deep the stack can go before four stops being four.

Four lamps, one group. The gap before lamp 1 is the group gap.

Set by ear at 390 ms, and that is now the floor in GAP_FLOOR.repeat — the tightest the station will read the repeats of one number however deep the level goes. Drag below it to hear why.

Set by ear at 780 ms — GAP_FLOOR.group, the gap the game leaves before a new number begins.
