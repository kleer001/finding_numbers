Overflow glitch lab

  

    Candidate treatments for levels past the authored range — the arcade board that
    keeps running after it has walked off the end of its own level table. Two families:
    static corruption, which is set once per room and holds still (this is what
    the Pac-Man 256 screen actually looks like), and raster faults, which move.
    Static reads as a broken machine; motion reads as a broken signal. Mixing too much
    of both reads as neither.
  


  


  

    
    
    
Master scale on every enabled effect. This is the dial a level number
      would drive: level 17 sits near the bottom, and it climbs from there.

  


  

    
    

      Two guarantees, both required for the level to stay playable. Corruption is
      masked off the walkable cells, and then the walkable cells are
      repainted last, after every other pass — so no effect, in any combination,
      can put ink where the player has to walk.
    

    

      
      
Also protects the ring of wall cells touching a corridor. Without
        this, DROPOUT punches holes in the wall right at a corridor edge and they read as
        doors — a hole you cannot walk through is a lie the player can't act on, which is
        a different thing from a room that moves its exit.

    

    

      
      
Diagnostic only — outlines what corruption may not touch.

    

  


  
static corruption — set per room, holds still


  

    
    

      
      
    

    

      
      
      
Pac-Man's level-256 screen corrupts one contiguous half and leaves
        the rest playable. A contiguous region reads as a memory fault; scatter reads as
        noise.

    

    

      
      
      
0 = frozen: the same cells stay wrong for as long as you stand in
        the room. Above 0 the corrupt set re-rolls, which stops reading as a broken board
        and starts reading as television static.

    

  


  

    
    

      
      
      
Wall cells blanked to the page color — the wall eaten through in
        patches. Cheapest effect here, and the only one that changes what the maze
        looks passable through without changing where the doors are.

    

  


  

    
    

      
      
    

    

      
      
      
Reverse-video patches: ink and page swapped over a block of cells,
        the way an 8-bit machine corrupts colour RAM independently of the character RAM.

    

  


  

    
    

      
      
      
How many numbers the station has read back. The status field is
        five columns wide, so anything past about five digits already has nowhere
        to go — the readout runs out of box on its own, well before any effect is applied.

    

    

      
      
      
The counter is a 4-bit field, so 16 is the largest number it can
        hold. What it prints from 17 on is the whole conceit in five characters.
